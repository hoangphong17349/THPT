📄 File đề kiểm tra

Đây là nơi duy nhất cần sửa khi muốn thay đề. Các trang khác chỉ lo giao diện và tự đọc đề từ file này.

Cách thay đề

  1. Mở file này bằng trình soạn thảo, sửa khối const EXAM = { ... } ngay bên dưới.
  2. Mỗi câu hỏi nằm trên một dòng; ans là chữ cái của đáp án đúng ("A", "B", "C" hoặc "D").
  3. Số thứ tự câu tự đánh theo vị trí, không cần gõ "Question 1." vào nội dung.
  4. Chỉ viết chữ thường, đừng chèn thẻ HTML hay ký tự < > vào nội dung.
  5. Lưu file rồi mở lại trang này: ô bên dưới báo xanh là đề hợp lệ, báo đỏ sẽ chỉ rõ câu nào sai.
